title: Introduction
description: rag-core adds scoped production retrieval to an existing Python application and agent.
---

rag-core is an embeddable Python retrieval engine for applications that already
own their infrastructure. Bind a tenant and index, ingest documents, and expose
the same scoped retrieval path to an agent.

It owns the retrieval path: ingest, chunking, indexing, search, context assembly,
traces, and eval hooks. Your application keeps authentication, tenancy,
connectors, chat, and generation. rag-core stays a retrieval core, not a hosted
service.

## Install

```bash
pip install rag-core   # or: uv add rag-core
```

## Add retrieval to an agent

```python
from agents import Agent
from rag_core import RAGCore

rag = RAGCore.from_env(index="company-docs")
agent = Agent(name="support", tools=[rag.tool()])
```

`RAG_CORE_TENANT_ID` and the index are bound before the model can call the tool.
The default retrieval path is dense-only. Sparse and hybrid plans remain
advanced, explicit options.

<Callout type="info">
  `Config.local()` and the local folder CLI are available for development and
  tests. Production applications normally configure an existing vector store and
  embedding provider.
</Callout>
